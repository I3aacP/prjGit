# ***Resolucion de Problemas***

La resolucion de problemas (en el area de programacion) tiene que ver con la algoritmia, aquella disciplina que busca patrones (Comportamientos, secuencias, etc) y trata de expresarlos matematicamente con el fin de hallar una solcion logica.

*Issues/bug:* Cuando el programa compila, mas sin embargo tiene un error de logica que impide el correcto funcionamiento.  

*Error:* Errores de sintaxis, por ejermplo la falta de ";"

    Problemas -> Hallan solucion de forma Matematica -> Entonces si o si hay solucion algoritmica
